エラーの原因を特定し、解決方法を提案します。

## 実行フロー

### パターンA: エラーメッセージから自動診断
ユーザーがエラーメッセージを提供した場合：
1. **スタックトレース解析**: エラー発生箇所を特定
2. **該当ファイルの読み込み**: 問題のあるコードを確認
3. **原因推定**: エラーの根本原因を分析
4. **解決策提案**: 具体的な修正コードを提示

### パターンB: ログファイルから自動検出
```
/explain/error
```
→ 以下を自動検索してエラーを特定：
- `logs/*.log` - アプリケーションログ
- 最近のGitコミット - 変更による問題の可能性
- テスト実行結果 - 失敗しているテスト

### 解説内容

1. **エラーサマリー**: エラーの種類とステータス
2. **原因**: なぜこのエラーが発生したか
3. **影響範囲**: どの機能が影響を受けるか
4. **解決手順**: ステップバイステップの修正方法
5. **修正コード**: Before/Afterの具体例
6. **検証方法**: 修正後の動作確認手順
7. **再発防止**: 同じエラーを防ぐための対策

### よくあるエラーパターン

- **NullPointerException**: null チェック不足
- **SQLIntegrityConstraintViolationException**: 制約違反
- **NoSuchBeanDefinitionException**: Spring DIの設定ミス
- **401 Unauthorized**: 認証エラー
- **403 Forbidden**: 認可エラー
- **404 Not Found**: エンドポイントまたはリソース不在
- **500 Internal Server Error**: サーバー内部エラー
